# Loop 与 Swarm 离线研究原型

`loop-swarm-showcase.html` 是从本地最终演示资产选择性迁入的自包含静态原型，用于核对目标架构、三类 Demo 和交互叙事。

它不是 `apps/web` 的替代入口，不连接 API、模型、数据库或真实办公系统，也不证明 Task Contract、长期任务分支、跨端控制或 Adaptive Swarm 已经实现。文件中的邮箱、客户、金额和任务均为演示 Fixture。

当前可运行产品、协议和安全边界仍以源码与 `docs/` 下的 V0.1 文档为准。后续实现应从 `TARGET_ARCHITECTURE.md` 的协议与测试顺序推进，不从静态 HTML 复制状态真值或执行结果。
