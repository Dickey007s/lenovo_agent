## 场景与根因

DR-0068 两条已采用数字错误通过同一个 Worker API 执行路径重放，baseline.xml 三项均失败：
两个错误仍被采用，交互输入仍只有 60 行。只读 Worker 原来始终以空 deterministic context 对账，
有引用便能进入采用；纯分析不生成文件，所以不能借用文件 Effect 作为计数权威。
传输总行数是 Preview 记录数，不能当作业务记录数。交接失败另有引用 JSON 元数据的历史反例。

修复把无渲染来源计算与文件构建分开，给同一个 Analyst 有界辅助和拒绝门；没有新建 Runtime。
模型仍可能在未覆盖措辞、规则解释和建议上出错，未知不得被写作“数值已验证”。
