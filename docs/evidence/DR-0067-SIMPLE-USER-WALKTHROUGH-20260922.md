## 观察与修正

| 观察 | 实施的修正 | 回归重点 |
| --- | --- | --- |
| 交付清单、分支、成果重复 | 保留一个工作项/成果区；摘要和证据逐项展开 | 第四/五项仍可找回，状态和来源绑定不变 |
| 协作回执挤走依赖图 | 图和当前影响先展示；交接与核对放入既有执行回执 | 分歧入口直达意见，调用/采用不混淆 |
| 成果追加在长页底部 | 专注成果和版本页，显式返回及 Escape，恢复入口焦点 | 详情不与进展堆叠，核对页 Escape 不穿透 |
