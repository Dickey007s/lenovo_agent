## 素材与实际运行

- [演示目录](../showcase/office-agent-20261023/)有八案、27 张 1600 × 1000 PNG，全部从本轮原界面捕获，无 AI 重绘。
- 五个 Demo1/2 案例复用原测试 Fixture，仅演示界面状态；捕获时研究任务 POST 由浏览器拦截，禁止落到真实服务。
- 三个 Demo3 案例通过原 localhost:3000 前端和固定规则 API 实际办理，使用各自独立 Owner。逐案 capture JSON 保存 Run ID、版本、状态和回执种类。
- 摘录：draft_ready 第 1 版 -> draft_ready 第 2 版；发件：awaiting_confirmation 第 1 版 -> 第 2 版 -> executed/test_message；材料判断：awaiting_decision -> decided/decision_note。
- Demo3 所有记录 model_called=false、external_action=none。没有真实邮件、审批或下游动作。
- 每次捕获检查页面错误为空、意外放行的研究请求为零；有图不等于真实 Provider 或文件下载验证。

## 走查发现与迭代

1. 初版财务截图只显示概览，后改为滚动到实际文件列表。
2. 发件长说明盖住核对项，后通过原界面折叠控件收起说明，保留正文、修改失效提示及勾选。
3. 大图下方才有翻页操作不方便，增加图上方固定翻页区；保留键盘与原尺寸浏览。
4. 手机副标题拆出单字，改短；保留可横向切换的案例条。
5. 财务成果兜底文案误称只有失败回执，修正为检查与分析分别表述。权威判断、业务否决和失败记录不变。

## 边界

不是完整 166 项全量回归。本轮未重跑生产构建、真实模型、PostgreSQL 重启、目标用户实验或企业连接器。
原系统生产代码只增加一个结果文案分支；其余新增是展示材料、捕获和检查脚本及治理文档。
只读工作包不是分布式蜂群；Worker 歧义恢复未被这个演示补成真实闭环。
“输入一段指令”是案例叙事：Demo3 当前依赖事项类型与结构化字段，不是自然语言意图解析。
