Demo 3 技术路径：五因子判定引擎

risk_judgement.py · 等级由规则算出，界面展示每一步

1办公动作输入

ActionInput
  • 类型：整理 / 摘录 / 建任务 / 发消息 / 对照
  • 对象：通讯录联系人（内部 / 外部）
  • 标题、正文、来源资料

2取因子值

judge_action()
  • 动作类型给默认值
  • 对象不明 → 按外部，标“不明按高”
  • 正文 / 资料含薪资、报价 → 高敏感
  • 最低价承诺、无须审批 → 无权

3判定

judge(ActionFactors)
  • 5 个因子查下限表
  • 6 条合并规则，顺序固定
  • 等级上限 × 动作形态 → AL
  • 介入原因排序，一次只问一件

4判定记录

RiskJudgement
  • 因子取值、下限、依据
  • 命中的规则与说明
  • 等级、上限、AL、此刻处理
  • 阈值版本 thresholds.default.v1

5界面与状态

office_action_policy · workflow_graph
  • 状态：自动 / 草稿 / 待确认 / 受限
  • L4 才要求三项核对
  • 8 维度说明标出“决定等级”
  • Risk Lens 展开判定面板
