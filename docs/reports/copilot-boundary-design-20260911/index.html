    研究详稿

    候选方案：有界授权 + 异常停靠

    低影响、可检查的范围内推进；越界、缺信息、版本变化或回执不明时分别处理。高影响动作仍按具体对象事前确认，政策禁令不能被确认覆盖。

    待对照验证
    方案什么时候找人潜在代价不能省略
    逐动作确认每个动作执行前重复提示、疲劳和机械批准动作后果与真实授权检查
    有界授权 + 异常停靠范围改变、关键不可逆动作、缺失信息等初始范围可能写错，越界检测也可能漏报明确范围、撤销、监控、失效与再核对
    粗粒度常驻规则按预先配置的类别询问类别可能遮蔽具体情境；少提示不等于更安全具体动作约束与用户效果验证

    先保留反证，再设计“更少打扰”

    一项 2026 年预印本的模拟办公实验发现：用户自定义规则减少了提示，却未带来更强的越界保护。不能把确认次数下降当作成功，也不能据此否定所有有界授权设计。
