本稿是首次快速汇总的历史口径。后续已整理八案例规则和蜂群差异，并在原能力页完成第一部分事实解释投影。最新汇报见 [三个 Demo 的边界与蜂群简稿](DEMO123-BOUNDARIES-AND-SWARM-BRIEF-20260912.md)；该增量不等于 Demo3 全部闭环完成。

## 可以直接讲

这阶段主要围绕办公 Agent 的人机共驾开展了调研，整理了共同计划、人工介入时机、用户监督和局部纠错等方向的论文与官方实践，近期重点核验了 6 篇论文和 3 篇官方材料。

据此，我们把 Demo3 的设计重点从简单的风险分级或统一“确认继续”，转向三个问题：什么时候需要人介入、用户具体决定什么、介入后系统如何接着完成任务。已梳理证据歧义、权限不足、版本变化、执行结果未知和主动接管等情形，并整理相应的交互草案与正反测试用例。

整体上不另起一套系统：保留原有 Agent Control Loop 的持续推进能力和 Adaptive Swarm 的协作框架，在现有任务进展、执行记录、协作与证据核对界面中整合人机共驾。当前完成的是调研、设计梳理和部分离线状态测试；新增共驾交互尚未整体接入原系统，不能说 Demo3 已完成。下一步优先验证一条真实的“发现问题、人工处理、局部继续、保留其他成果”的流程。

## 调研支持了哪些判断

- **共驾不只是批准。** Cocoa 允许人和 Agent 分配步骤，并在部分执行后调整计划；这为“执行中纠偏”提供设计参照，不证明我们的产品已经具备这项能力。[Cocoa，CHI 2026，v4](https://arxiv.org/abs/2412.10999v4)
- **参与不等于有效监督。** Plan-Then-Execute 在模拟日常任务中考察计划与执行参与，指出看似合理的计划可能导致错误信任。因此测试要看用户能否发现错误，不能只看是否点击了确认。[Plan-Then-Execute，2025](https://arxiv.org/abs/2502.01390)
- **检查点要有理由，而非每步都打扰。** When Should Users Check? 研究检查与返工的时间成本。我们的推论是：区分效率检查与必要授权，不能用省时跳过权限要求。[When Should Users Check?，CHI 2026，v3](https://arxiv.org/abs/2510.05307v3)
- **共同计划、过程介入、动作审批应分别设计。** Magentic-UI 的官方介绍提供了相应交互参照；其发布博客的模拟用户评估不等于普通办公用户收益。[Microsoft 官方介绍，2025-05-19](https://www.microsoft.com/en-us/research/blog/magentic-ui-an-experimental-human-centered-web-agent/)

以上为定向研究，不是完整行业综述。完整日期、样本、阅读范围和限制保留在 [来源台账与阅读路线](copilot-boundary-design-20260911/research/followup-20260912/recommendations.md)。本次快速复核四个核心原始入口，不重复计为新增四篇材料。

## 原系统与新增材料的关系

- **原系统保留。** `/` 是办公资料库，`/agent-capabilities` 保留执行进展、完整执行记录和 Adaptive Swarm 协作视图。前期 UI 修改落在原系统代码中，没有被研究 HTML 替换。
- **新增 HTML 是辅助材料。** 研究资料库和共驾离线原型不是正式产品入口；让它们占据交付中心造成了混淆，需要纠正。部分离线交互存在，不代表相应后端权限、外部执行或恢复协议已实现。
- **后续必须原位整合。** 沿用 Task/Run/Snapshot、Branch、DecisionRequest 和版本记录，优先复用现有证据核对、暂停与分支继续机制；新增语义超出现有合同的部分先做协议评审，不把本地模拟状态接成服务端事实。

建议首先在原系统演示：两项分析已完成，另一项因引用位置歧义等待处理；用户查看原文并选择位置，再按当前 Run 状态执行合法的分支继续，其他成果保持。旧 Run 已结束时应创建同 Task 的新 Run，不伪装成旧 Run 续跑。这是拟选的集成验收路径，本轮没有执行它。

## 本轮核对与边界

本轮读取原系统入口与组件源码，确认两个入口均使用 `HarnessWorkbench`，Loop/协作/证据审查组件以及后端 continuation、只读 Worker 接口仍在；未改动业务源码、未启动模型任务，也未进行功能回归。检查时默认 3000/8010 端口未监听，只表示当前服务未启动，不是代码丢失。

此前离线原型的 60 项 Node 测试只覆盖合成状态、文案和研究展示逻辑，不能写成原系统 Demo3 集成通过。最终浏览器和真实目标用户理解仍待验证；当前不具备真实外发或通用外部动作授权能力。
