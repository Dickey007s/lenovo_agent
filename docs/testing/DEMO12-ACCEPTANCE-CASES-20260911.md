## AC-01：从协作页新建任务

- 成本：不提交任务，不调用模型。
- 前提：打开能力页；可以有旧任务，也可以已处于空白草稿。
- 操作：切换“协作方式” → 右上角“+ 新建任务” → 输入任意文字但不提交 → 再切协作 → 再次点“+”。
- 预期：每次都回到“执行进展”，出现空白输入框并自动聚焦；地址无 `#adaptive-swarm`。
- 继续检查：刷新仍是空白草稿；历史会话可打开原任务，原成果和状态保留。
- 失败判据：只看到草稿提示却没有输入框；仍留在协作页；创建空 Task；旧任务被停止或删除。
- 本次结果：实际页面先复现失败；新增自动化先红后绿；修复后在有 Run 和连续空草稿场景都通过。

## AC-02：真实只读日志核对

成本：提交后调用当前配置的真实 Provider；本次实际消耗 3 次模型调用。重新运行的调用数和输出可能不同。

可复制原始输入：

```text
只读核对算法研发中的 workflow.py 与 search_agent.log，检查设计路由与实际运行记录是否一致。逐项给出事实、影响、原文位置；不能定位时明确等待核对。不要修改文件，不要执行代码，不要发起外部动作。
```

操作：新建任务 → 填入输入 → 开始工作 → 查看完整执行记录 → 展开模型调用回执和服务端事件 → 查看成果与原文。

预期的运行边界：来源由服务端批准；调用/采用分开；引用歧义停在最小分支；不得执行源代码或修改原件。

预期的内容边界：必须区分日志中的两次启动，或明确声明仅分析了部分内容。不能把前半段结论外推为整份日志。

人工核验点（当前冻结原文的行号，不是模型必须生成的文案）：

| 范围 | 原文事实 | 不能混淆 |
| --- | --- | --- |
| 1–112 行 | 10:31 启动；13/39/65/91 行分类为 factual | 只代表这一段 |
| 113 行之后 | 10:32 再次启动；125 comparison、155 news、182 tutorial、212 news | 不能说全文件只有四条 factual |
| 155–162、212–216 行 | news 与 web_search_news 路由确实出现 | 不能全局断言从未触发新闻路由 |

本次结果：运行边界通过，内容完整性**未通过**。Run 保留 v1 两条发现并暂停，4 个候选位置未被代选。
摘要只覆盖前半段且没有清楚限定范围；源码显示模型单文件输入上限为 12,000 字符，该日志在约第 109 行截断，后段反例不在输入中。
这一问题仍未解决，不能把它归结为“模型没仔细看完整日志”，也不能靠调高上限冒充通用全文检索已完成。

## AC-03：有上下文的证据选择

- 成本：只打开、预览、暂缓不调用模型；点击确认继续可能消费下一轮预算。
- 前提：AC-02 当前保留的 waiting Run，或自动化构造的 ambiguous Resolution。新的 Provider 运行不保证再次生成歧义。
- 操作：确认引用位置 → 先看“待核对判断” → 在文件中查看 → 返回任务进展 → 重新打开。
- 预期：看见本次判断的标题与摘要，明确“尚未确认”；候选个数来自实际 Snapshot；无默认选择；仅预览不会启用确认。
- 失败判据：不知道正在验证哪个判断；看原文等于批准；关闭后自动跑下一轮；把选择位置写成批准结论。
- 本次结果：修复了判断上下文缺失；实际显示 4 个候选，预览第 13 行成功，0 个选中，关闭写入 defer，调用数仍为 3。

## AC-04：确认失败仍能退出

- 成本：受控 Playwright，零真实 Provider 调用。
- 操作：测试注入确认 409；选择候选并确认；再关闭并注入 defer 409。
- 预期：不伪造确认成功，结果未知明确显示；核对页立即退出，工作面留下暂缓未写入提示。
- 失败判据：被困在核对页；丢失错误；网络失败却显示已确认。
- 重跑：`pnpm --dir apps/web exec playwright test --grep 'redesign preserves failed confirmation'`。
- 本次结果：纳入本次全量回归；它证明异常交互，不是数据库冲突实测。

## AC-05：Demo 2 协作不是一张静态图

- 成本：受控 Playwright，零真实 Provider 调用。
- 操作：运行已有 Demo 1/2 runtime acceptance 用例，依次检查准入、第一波、局部等待、保留贡献、下一波与历史。
- 预期：未经确认没有 Worker 回执；每批最多 3 个；采用和返回分开；等待分支不抹去已有成果；没有 ready 单元时不能空派发。
- 失败判据：只换动画却没有请求/回执变化；一条分支失败导致其他成果消失；没有调用却显示已执行。
- 重跑：`pnpm --dir apps/web exec playwright test --grep 'Demo 1/2 runtime acceptance'`。
- 本次结果：纳入本次全量回归；本次没有实际 Provider 多 Worker 或 PostgreSQL 重启联测。
