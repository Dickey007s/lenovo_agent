这张展示 Agent Control Loop 中需要人工选择证据位置时的界面。系统先说明为什么需要人参与，以及选择会影响哪一部分。右边展示实际候选原文，而不是让用户猜行号，也不替用户默认选择。选定依据只是解决引用位置，不等于批准业务结论，更不会授予外发权限。恢复时沿用已有成果，只处理相关分支；如果旧 Run 已经结束，需要按合同创建同一任务的子 Run，不能假装旧 Run 又恢复执行。
