# USER-FEEDBACK-20260825-13: Broader FORTE test suite

## Source type

Stakeholder product and evaluation feedback. This is a direct project request,
not a target-user study.

## Verbatim feedback

> 1. 我希望有更多的办公案例，你提供一份测试用例文档给我，涵盖不同类型的任务，可以参考数据集的划分
> 2. 我现在想知道你有没有把整个数据集下载下来，整个数据集下载下来或许是太庞大了，十几个G的数据，但是你现在只有八九分文档貌似也太少了，能干的任务范围比较少。你把测试集下载下来吧，起码涵盖不同的文件和不同的任务才行吧

## Supports

- The evaluation plan must cover substantially more professions, source
  formats, task topologies, output types, and governance conditions than the
  first three FORTE scenarios.
- The repository must state exactly which upstream bytes were downloaded and
  which of those bytes the current product can actually use.
- A test-case catalog should make the broader dataset useful for systematic
  development rather than treating additional files as decorative samples.

## Does not support

- This feedback does not prove that FORTE publishes its complete 180-task
  benchmark, that the public download is tens of gigabytes, or that every
  downloaded task is already executable in the current Agent Harness.
- It is not user research and does not prove broader task success,
  generalization, usability, or production readiness.
