# 用户反馈：增加“新建任务”入口

- 日期：2026-09-03，Asia/Shanghai
- 类型：Stakeholder 直接产品反馈
- 对应决策：`DR-0060`
- 对应场景：`SCENARIO-047`

## 原始诉求

> 我想你在系统中加一个新建对话的功能，让我能新建任务。

## 产品解释

当前产品以服务端 `task_id` 表示任务会话，以 `run_id` 表示一次有界执行。因此“新建对话”
落实为显式“新建任务”入口：先进入空白浏览器草稿，用户填写目标并启动后，才由既有
`POST /v1/harness/runs` 创建新的独立 Task 和首个 Run。

## 约束

- 点击入口本身不能创建空 Task、调用模型或消费预算；
- 不能停止、删除、覆盖或复用上一任务；
- 上一任务仍可从任务会话历史返回；
- 新任务可以使用与旧任务相同的文字，但必须使用新的启动幂等键；
- 该反馈不证明目标用户理解、效率、信任或任务质量改善。
