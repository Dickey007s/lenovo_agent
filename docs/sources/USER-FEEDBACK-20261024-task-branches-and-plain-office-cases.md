# USER-FEEDBACK-20261024-TASK-BRANCHES

日期：2026-10-24。类型：当前工作区对话中的用户直接反馈；不是目标用户研究。

原话摘录：

> 执行建议时不应新建任务，而应在原任务内用分支来展示——本质上它还是同一个任务。

> 第1轮要给用户展现过程——明确任务要干什么，把输入、Agent处理的文件、要达到的目的讲清楚，先跟用户对齐。

> 有没有一些简单点的，比如说一些Excel的、Word文档的，或者更加直观一点的展示形式。

支持判断：同一任务的后续工作保持身份与历史；首轮展示目标、文件和处理安排；采用普通办公样例。
不支持判断：必须展示模型私有思维链、必须复制所有历史模型内容、任意历史节点分叉、用户理解率提升、真实业务批准。

对应 DR-0087 / SCENARIO-074；没有新增附件或论文证据。
