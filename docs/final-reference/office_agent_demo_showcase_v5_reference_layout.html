Agent 最小功能模块

八个常驻 Runtime 组件构成底座；Swarm 只在复杂任务中按需增强。

Task Contract · 任务契约 明确目标、材料边界、交付物、完成条件与截止时间。
Durable Task State · 持久状态 保存事件、阶段、分支、版本、决定与工件引用。
Context State Manager · 上下文状态 按来源、权限和任务阶段组装可用上下文。
Execution Loop · 执行循环 持续观察、计划、行动、验证并提交结构化状态。
Capability Runtime · 能力运行时 统一调度模型、工具、连接器和临时 Worker。
Evidence & Quality Verifier · 证据验证 检查来源、事实口径、覆盖度、引用和产物质量。
Control Policy · 控制策略 管理 Evidence Gate、预算、停止、纠偏和接管。
Trace & Checkpoints · 追踪检查点 记录运行轨迹、证据、状态提交、回退与审计。
