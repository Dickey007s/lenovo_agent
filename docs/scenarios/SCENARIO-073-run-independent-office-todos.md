# SCENARIO-073：多个办公待办独立执行，证据中断可以看懂

- 状态：Limited Verified，限定工程测试和本次真实模型运行。
- 决策：[DR-0086](../decisions/DR-0086-automatic-readonly-todos-and-visible-evidence.md)。
- 来源：[USER-FEEDBACK-20261024](../sources/USER-FEEDBACK-20261024-live-demo12.md)。
- Evidence：[实跑记录](../evidence/DR-0086-LIVE-DEMO12-20261024.md)。
- 用户：同时处理资料摘录、代码阅读与跨职能核对的办公用户/演示者。
- 触发：一次列出三个待办，希望系统自己选合适的执行方式；部分证据存在疑问时要看懂边界。
- 痛点：以前是一个目标拆工作包，每波还要确认；暂停时虽有草稿，依据页却可能空白。
- 目标：每项真实 API 执行、各自评估路由、有明确来源与未完成项，不让用户搬运 Agent 对话。
- 完成条件：三份不同 Task 回执；两类执行路线可观察；自动 Worker 不额外要求确认；已采用结果有可定位引用；异常不伪造全完成。

## 主路径

1. Demo2 待办页预填三项，可修改；点击之前没有模型调用。
2. 点击开始全部待办，明确三个只读任务各自预算。
3. 浏览器分别提交三次 POST /runs，不等待上一项模型执行结束。
4. 每项 Planner 返回计划；服务端选单控制器、固定顺序或只读协作。
5. 自主策略获准的 Worker 自动启动与合入，依赖满足后可继续下一波。
6. 用户从任务列表打开分工、依据或成果，查看本次真实回执；不是三个独立产品。
7. Demo1 按单任务入口实跑规则摘录、批准依据核对、代码与日志对照；有引用问题时显示暂停范围与保留草稿原文。

## 异常路径

- 请求响应丢失：当前页面锁定原任务内容，原 key 重试；已确认任务不重复启动。跨刷新未知请求恢复尚未实现。
- 无批准源、歧义、结构失败：不猜答案；已有成果和其他独立任务保留。
- 暂停/停止：当前已收到的贡献按原合入规则保留，下一波不自动发出。
- 版本变化/预算不足：自动派发停止，不自动扩大预算或反复重试。
- 人工判断/副作用计划：自主只读授权不覆盖，系统停止该项。
- 重启：沿用原检查点暂停规则；本次实跑服务为隔离 memory，历史公有快照已导出，不声称重启后会自动恢复。
