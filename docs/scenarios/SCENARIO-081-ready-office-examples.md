# SCENARIO-081：在当前入口演示可复核办公任务

- 用户：准备展示系统的项目同学与初次观看者。
- 触发：页面显示执行失败，看不清哪些任务适合展示。
- 痛点：前后台版本不一致；模型任务跑完但遗漏目标；宽泛摘要作额外推断。
- 目标：同一入口展示指令、真实处理、可定位结果和明确的人工边界。
- 完成条件：推荐案例有运行编号、模型回执、已采用输出、可打开来源和逐项验收记录。
- 正常流程：打开 3000 → Demo1 折叠示例或 Demo2 待办 → 核对输入 → 提交 → 查看任务/依据/成果。
- 异常流程：旧 API 参数拒绝先解决服务版本；缺凭证显示待补资料；未批准权限变更保留人工选择；模型漏项不列为完整演示。
- 前台：示例默认折叠；不预选人工决定，不因打开示例调用模型，不隐藏已有问题历史。
- 后台：原 Task/Run、版本、幂等、只读策略与证据门不变。public Snapshot 为状态权威。
- 来源：USER-FEEDBACK-20261025-DEMO-READINESS；仅为本地样例，不代表真实用户研究。
- 验证：Limited Verified，见 DR-0094 Evidence；无外部业务动作、无通用正确性保证。
