# SCENARIO-009：让 Agent 研究当前办公文件夹并提出下一步

| 字段 | 内容 |
| --- | --- |
| Scenario ID | `SCENARIO-009` |
| 状态 | `Limited Verified`；最多三轮、FORTE 公开输入、单进程 memory、严格只读 |
| 决策 | [`DR-0023`](../decisions/DR-0023-agent-control-loop.md) |
| 来源 | `USER-FEEDBACK-20260825-CONTROL-LOOP-16` |

## 目标用户与触发条件

目标用户是面对一个已有项目资料夹、但还不知道下一步该推进什么的项目负责人、
分析人员或办公知识工作者。用户希望 Agent 先研究当前资料，在有限时间和范围内
补充证据，再给出可以复核的推进建议，而不是一次性生成泛化总结。

## 当前痛点

实现前的 Runtime 只对用户预先选中的文件执行一次规划和一次只读分析。当前纵切已能
根据第一轮未覆盖文件形成 Evidence Gap，并由服务端在预算内进入第二轮；用户也能查看
继续或停止原因并提交 pause、steer、resume、stop。仍缺的不是第二轮本身，而是语义级
验证、耐久恢复、真实工具执行和生产身份边界。

## 目标与完成条件

用户设定研究目标、允许的文件范围和预算后，Agent 最多运行三轮。每轮都要显示
研究问题、实际读取文件、发现、验证、证据缺口、剩余预算和下一步决定。最终输出
必须包含可点击来源、推进建议、未覆盖范围、相互冲突的证据和仍需人工判断的问题。

## 主流程

1. 用户在完整文件夹中选择 1-20 份允许文件，输入研究目标和完成条件。
2. 服务端冻结 Task Contract，显示最大轮次、文件、模型调用与时间预算。
3. Round 1 读取目录索引，选择并安全解析不超过 8 份文件。
4. Planner 形成有界研究计划；服务端编译和校验允许的只读操作。
5. Analyst 生成带引用的发现；Verifier 检查 Schema、引用成员关系和只读边界。
6. Evidence Gate 若发现缺口且预算允许，生成下一轮问题和候选文件理由。
7. Evidence Gate 在预算内自动进入下一轮；用户可以在安全点暂停、继续、调整下一轮方向或停止，Round 2 不能覆盖 Round 1。
8. 证据满足、用户停止或预算耗尽时，服务端提交一份只读 Agent Control Loop Brief。

## 关键异常路径

| 异常 | 前台反馈 | 恢复动作 |
| --- | --- | --- |
| 候选文件超出冻结范围 | “候选计划未采用” | 服务端最多进行一次预算内修复；需要扩大范围时新建 Run |
| 文件发生变化或 hash 不一致 | 当前轮停止，旧证据保留 | 重新冻结文件后开始新轮 |
| 模型输出未通过 Schema/Policy | “模型已返回但未采用” | 重试本轮或停止，不沿用猜测结果 |
| Evidence Gate 发现显式缺口 | 展示缺失资料和下一轮目的 | 在冻结范围与预算内继续、调整下一轮方向或停止 |
| 预算耗尽 | 显示耗尽的具体预算与未完成项 | 结束并提交有限结论，或新建更大预算 Run |
| 用户暂停或 SSE 断线 | 区分业务暂停与传输重连 | resume 命令或按 sequence/Snapshot 对账 |

## 前台验收

- 首屏仍可自由浏览完整文件夹，不退化为 Scenario 选择器；
- Run 运行后按 Round 展示，而不是把所有事件堆成一条技术日志；
- 每轮都能看见“为什么读、读了什么、发现什么、为什么继续或停止”；
- 只有 Evidence Gap 相关候选文件被高亮，Agent 不会静默扩大读取范围；
- pause、steer、resume、stop 各自有等待确认、成功、失败和版本冲突反馈；
- 最终建议逐项可以回开来源，未覆盖目录不会被包装成已分析；
- 普通 UI 不出现 Prompt、思维链、绝对路径、内部 ID、原始策略码或 provider response。

## 当前证据与边界

实现 `8364b1e` 和 [Evidence](../evidence/AGENT-CONTROL-LOOP-BOUNDED-READONLY-EVIDENCE-20260825.md)
证明了一次真实 `deepseek-v4-pro` 路径：8 份 FORTE 文件、2 轮、5 次模型调用、第一轮
Evidence Gap 触发第二轮、21 条服务端事件并提交只读 Brief。第一轮第一个计划未通过
服务端校验，系统写入“未采用”事件并在同一预算内重试一次。

当前 Run、Round、Event、Control 与 Brief 仍只存在单 API 进程 memory；API 重启不恢复，
浏览器也没有历史 Run 选择。pause/stop 只在模型调用之间生效，deadline 不硬取消在途请求。
Evidence Gate 只证明引用属于允许文件，不证明语义真值。没有用户研究、真实 Connector、
生产身份、不可变 ArtifactVersion 或跨实例证据，因此场景不能扩展成完整长期 Agent 结论。
