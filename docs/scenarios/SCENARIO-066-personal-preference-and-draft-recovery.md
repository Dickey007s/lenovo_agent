# SCENARIO-066：重复整理、误改草稿和找回暂缓事项

- 用户：经常整理个人备忘、准备内部摘录并核对业务材料的办公人员。
- 触发：每次重选排版；误改摘录后需要旧内容；暂缓判断后找不到事项。
- 当前痛点：不能记住整理方式；历史可读但需手动复制；最近记录混杂已结束事项。
- 目标：让可逆的小操作方便，同时不把个人偏好变成执行授权。
- 完成条件：偏好可撤回、实际输出遵守选项；旧内容经预览保存为新版本；待处理筛选能重开原事项且不执行。

## 用户流程

1. 选择紧凑整理，显式记住，开始后由固定工具生成文本副本。
2. 新事项沿用偏好；清除后下一次恢复默认。发件仍须当前三项核对。
3. 在摘录历史取回旧内容，先检查编辑区；放弃不写入，保存追加版本。
4. 暂缓材料分歧，办理另一件，再筛选最近待处理，重开原事项后明确选择与理由。

## 异常路径

本地存储不可写：显示未保存，本次选项仍可使用。非法枚举或用于其他操作：服务端拒绝。
草稿过期：沿用 409 刷新与旧核对清空，不覆盖新版。未知结果、只读或未提交编辑：禁用恢复。
最近列表查询失败显示错误；空筛选只说明近二十个 Run 内没有待处理，不保证全库无待办。
不支持历史内容缺失时猜测恢复，也不提供发件召回。
