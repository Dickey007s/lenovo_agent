# SCENARIO-032：从三个期间工作簿形成可回开的财务风险候选

## 用户与触发

- 用户：需要先整理期末未付、未收和跨期异常线索，再由财务人员复核处置的财务运营人员。
- 触发：输入“核对三期往来明细，生成未付统计、未收统计，并判断是否存在僵尸账款。”
- 痛点：旧实现把“没有候选”写成成功答案，来源真的出现候选时可能误报系统失败；用户也容易把三期任务上下文误解为两个 2026 CSV 已合并三个期间。

## 主路径

1. Planner 在整库冻结索引中自主选择证据；固定 TC-05 效果门另行冻结三份批准 XLSX 原始字节。
2. 服务端校验三个逻辑期间、文件名、展示路径、allowlist、声明大小和字节唯一性，再解析单工作表、固定十列、业务行、方向、金额与 Excel 位置。
3. 2026 正数贷方期末余额生成未付 CSV，2026 正数借方期末余额生成未收 CSV；每行都带 2026 来源和 locator。
4. 服务端按“科目+客商”比较三个期间的正数借方期末余额。三期金额完全相同时形成风险候选，并保留三个来源位置。
5. Runtime 在隔离 Run Workspace 生成两个 CSV 和一份 Markdown；Verifier 重读批准 XLSX 与生成字节，复算明细、合计、排序、候选和边界。
6. 前台先说明候选不是会计动作，再分开显示确定性检查、当前明细/候选和最终财务待决；候选可展开到三期金额与 locator。

## 当前固定输入结论

- 2026 期末未付为 31 条正数贷方余额，合计 `3,984,606.46`。
- 2026 期末未收为 2 条正数借方余额，合计 `4,992,891.47`。
- 当前三期启发式候选为 0 条；这不等于没有账务风险，仍需财务复核。
- 来源变异把 2026 年“绵阳长城发展融资担保有限公司”的借方期末余额由 170 万改为 150 万后，与 2025 上半年、下半年同键同额，候选动态变为 1 条；这是测试副本，不修改 FORTE 原件。

## 异常路径

- 缺失、重复或额外来源，同一内容冒充两个期间，错路径、空或损坏 XLSX：来源合同失败，不生成绿色成果。
- 表头重复或错位、未知方向、非法/非有限金额、公式、错误单元格、同期间重复键：明确 fail closed，不按旧样本答案兜底。
- 候选大于 0：计算仍可通过，前台显示琥珀色“需财务复核”，不红成系统故障。
- CSV/Markdown 任一结构、金额、行、定位、候选或边界检查失败：三个 Artifact 与 EffectReceipt 变红，不显示可靠财务成果。
- Planner/Analyst 另有 Evidence Gap：确定性 Artifact 与财务 outcome 保留，整个 Run 可以继续处于 `waiting_input`。

## 完成条件

- 三份成果可下载并独立解析；两个 CSV 只含 2026 来源，Markdown 含三个期间及候选方法和局限。
- 2026 明细数量、金额、排序、唯一键和每个 locator 可从批准来源重算；候选集合可从三个期间重新推导。
- 合法来源变异只改变受影响的明细、合计或候选；候选 0 与候选大于 0 都可通过确定性验证。
- 原 FORTE 输入字节不变，`external_action=none`；没有付款、核销、记账或坏账确认。
