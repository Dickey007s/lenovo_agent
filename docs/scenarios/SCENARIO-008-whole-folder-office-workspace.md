# SCENARIO-008：浏览完整办公文件夹并下达原创任务

| 字段 | 内容 |
| --- | --- |
| Scenario ID | `SCENARIO-008` |
| 状态 | 限定工程路径为 `Limited Verified`；用户理解和用户价值仍为 `Draft` |
| 决策 | [`DR-0022`](../decisions/DR-0022-workspace-folder-and-arbitrary-task-contract.md) |
| 来源 | `USER-FEEDBACK-20260825-WHOLE-FOLDER-14`、`FORTE-PUBLIC-SUITE-INVENTORY-20260825` |

## 目标用户与触发条件

目标用户是进入共享业务文件夹的办公知识工作者或产品评审者。系统不替他们
预先选择 Demo；用户需要先了解现有材料，再选择一个可辩护的数据范围，提出
本轮具体任务。

## 当前痛点

注册 Scenario 的入口容易让产品看起来像写死的演示。用户无法先建立对办公资料
的理解，也难以判断 Agent 能否组合预设案例之外的文件。

## 目标与完成条件

用户可以浏览全部公开 FORTE 文件夹，打开 CSV/PDF/DOCX/TXT、Spreadsheet
和代码文件的安全预览，跨文件夹选择材料，并写出原创任务。初步结果中的每条
引用都必须能重新打开本轮冻结范围内的准确来源文件。结果始终标记为待人工复核，
并明确说明没有发生外部动作。

## 主流程

1. 根页面载入一个办公资料库，展示文件夹和文件数量。
2. 用户在调用模型前搜索文件、查看元信息并打开安全预览。
3. 服务端重新校验文件字节，返回有界的只读预览。
4. 用户从任意文件夹选择 1 到 20 份文件，输入自己的任务。
5. 服务端冻结 `file_ref`；Planner 的业务意图由服务端策略编译和校验。
6. Analyst 只接收选中文件的安全内容投影。
7. 用户查看 named SSE 轨迹和两次模型回执，再检查计划与初步结论。
8. 用户点击引用，重新打开对应业务文件的安全预览。

## 具体办公任务

| 任务 | 文件组合 | 预期交互 | 当前边界 |
| --- | --- | --- | --- |
| 跨期财务核对 | 三份 XLSX | 选择期间、查找稳定余额、返回被引用 Sheet | 模型数字仍需确定性核验 |
| 入职物资匹配 | CSV 加 PDF 制度 | 查看人员与规则、识别例外、在歧义处暂停 | 只读结果，不创建账号或采购 |
| 简历与 JD 对比 | DOCX 加 PDF | 选择岗位和候选人，按标准逐项核对证据 | 敏感招聘决定由人负责 |
| 上线准备检查 | Markdown 加 XLSX | 合并需求与测试报告，检查冲突事实 | 不执行真实上线或创建 Issue |
| 故障诊断 | TXT 日志 | 生成时间线和有界修复建议 | 命令只是建议，不会执行 |
| 跨文件夹综合 | 两类职业的文件 | 提出 FORTE 原任务中没有的新问题 | 来源范围受控，语义质量未证明 |

## 失败与恢复

| 失败 | 前台反馈 | 恢复方式 |
| --- | --- | --- |
| Workspace manifest 或文件 hash 异常 | 显示完整性异常，不调用模型 | 修复或重新导入文件后重试 |
| 不支持、加密或含 active content 的文件 | 明确说明预览不可用 | 选择其他文件或增加经审查的 Adapter |
| 没有选文件或任务过短 | “运行任务”不可用 | 明确选择范围并补全任务 |
| 模型输出未通过 Schema/Policy | 显示“模型已返回但未采用”，Run 安全停止 | 修改任务或开始新一轮 |
| SSE 中断 | 显示重连中，并按 `after=N` 恢复 | 以服务端 Snapshot 为准 |
| 结果引用未选择文件 | 服务端确定性拒绝结果 | 不把该结果显示为完成 |

## 前台验收

- 主页面不存在 Scenario 或 Demo 选择器。
- 在 390 px 视口中，文件浏览、任务输入、预览、轨迹和结果均可访问，
  页面没有横向溢出。
- CSV/PDF/DOCX/TXT 的预览安全事实可见，但原始路径和 hash 不进入 DOM。
- 模型调用、模型内容采用和计划/结果校验分别呈现。
- 点击引用可以打开准确来源文件。
- 普通 DOM 不包含 task prompt、rubric、solution、绝对路径、digest、Prompt、
  chain-of-thought 或原始策略标识。

## 研究边界

本场景来源于 Stakeholder 反馈、FORTE 公开文件和主流 Agent 官方资料研究。
它还没有目标用户研究支持。“文件夹优先流程降低认知负担”或“提升用户信任”
仍是需要形成性测试的假设。
