# SCENARIO-063：看清任务交付，按需核对过程

- 用户：复核办公任务结果的使用者，以及听项目汇报的老师 / 同事。
- 触发：任务结束后只想看结果，却被禁用控件和调度信息占据首屏；听众不明白证据捕获和协作区别。
- 正常路径：当前成果 -> 业务结论 -> 查看成果 / 下载 -> 按需展开用途或执行方式。
- 异常路径：文件检查失败、业务否决、输入限制和未完成分支直接显示；暂停 / 续办 / Worker 确认仍保留。
- 对照：单轮终态无轮次切换、无无效人工控制；多轮仍可回看；完整能力页保持。
- 汇报：从真实 PRD 锚点解释来源 / 定位 / 采用，从真实两波记录解释直接依赖和部分采用。
- 完成条件：原路由、业务按钮、待决与权威字段不变；详情可键盘打开；无额外 POST；桌面与手机不溢出。
