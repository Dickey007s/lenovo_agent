# SCENARIO-071：从示例指令理解办公 Agent 的能力

日期：2026-10-23。状态：Limited Verified，验证范围见 DR-0084 Evidence。
来源：USER-FEEDBACK-20261023-CAPABILITY-SHOWCASE，用户附件和现有原系统，不是目标用户研究。
目标用户：第一次了解系统、需要演示或评审它的业务人员。
触发：需要短时间说明任务输入、系统过程、人工介入及实际产出。
痛点：只看抽象能力名或动态过程，看不出系统完成什么、哪些动作没有发生。
目标：不先理解内部术语也能逐案观察，同一工作台的三种能力不被误解为三个产品。
完成条件：八案均可从指令翻到末步，图可放大，来源和能力边界可查，不触发实时任务。

## 正常路径

1. 选择任务推进、协作或人机共驾能力栏。
2. 点击任务，看到完整案例指令及来源标签。
3. 按步骤翻图，对照系统处理、人工决定和产出；需要时放大到原尺寸。
4. 查看本案产出和边界，切换下一案。
5. 可复制指令并打开本机工作台，自行填写后明确提交；不会自动启动。

## 异常路径

无截图显示错误和重试；复制受限时选中文本并说明；非法 hash 回退到有效案例和步骤。
小屏案例横向浏览，页面无横向溢出；大图允许内部平移，Escape 关闭并返回触发按钮。
已通过文件与无当前分析并存时，原成果页不再说“仅失败回执”，但也不声明确定性结论或业务获批。
