# SCENARIO-082：在同一工作台看清待办、分工与人工边界

- 用户：首次观看演示的同学，以及实际操作任务的项目成员。
- 触发：Demo2 总览堆叠指令与统计，Demo3 表单及多层卡片与另外两个工作区风格不一致。
- 目标：先看任务和结果，细节按需展开；需要人处理的内容与操作不被精简掉。
- Demo2 正常流程：编辑待办 → 启动 → 查看状态和一条结果摘要 → 展开其余结果或进入任务 → 查看实际 Agent 分工 → 返回同组待办。
- Demo2 异常流程：启动错误、执行失败、缺源或未完成任务继续可见；不得因其他任务完成而隐藏它们。
- Demo3 正常流程：选择事项类型 → 核对内容 → 直接整理、编辑摘录、强确认或明确判断 → 查看结果和来源，按需打开操作记录。
- Demo3 异常流程：修改后旧核对失效；材料无预选；未知结果只能核对和重试原请求；受限事项无执行按钮；历史只读仍禁止写入。
- 展示条件：隐藏的任务/依据面板不在总览底部出现；桌面与 390px 窄屏无横向溢出；主任务终态和工作项回执一致后才截图。
- 来源：USER-FEEDBACK-20261026-UNIFIED-DEMOS-AND-SLIDES；真实走查为开发者自查，不是目标用户研究。
- 后端：现有 Task/Run、来源范围、Worker 准入、预算、版本和固定规则事项合同不变。
- 验证：Limited Verified，见 DR-0095 Evidence；模型实跑、固定规则走查、受控浏览器回归分别记录。
