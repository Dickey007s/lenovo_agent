# DR-0095：三个演示工作区的信息层次统一

日期：2026-10-26。状态：Limited Verified，仅限本轮界面投影与已记录的回归路径。
实现：现有未提交工作树；没有新提交或 PR。

## 场景与来源

[用户原话](../sources/USER-FEEDBACK-20261026-unified-demos-and-slides.md)要求先将 Demo2、Demo3 对齐 Demo1，再重新演示并更新网页，最后按两份参考 PPT 的模板整理汇报。
[SCENARIO-082](../scenarios/SCENARIO-082-unified-demo-overview-and-action-review.md)定义本轮界面验收。
本决定覆盖原工作台的信息层次调整，不引入独立产品入口，不改变各 Demo 的业务边界。

## 前台交互影响

Demo2 总览默认保留任务目标、真实状态、一条结果摘要及查看任务入口；完整指令、调用次数、预算和其余已完成结果按需展开。
错误、未完成工作与待处理内容不随普通详情折叠。协作图保留真实 Agent 数量、工作状态和调整结果；没有新增工作的详细理由收起，未伪造新增节点。

Demo3 沿用蓝白工作台、紧凑标题和细分隔线。类型与标题并排，整理偏好默认收起，最近事项放在当前操作之后。
状态与版本合并，正文、来源对照和结果下载不再层层套卡。强确认、未保存编辑、未知请求、风险、拒绝、人工判断与历史只读控制保留。
L4/L5 的影响与处理依据仍默认展开。材料选择仍无默认值；变更后的核对仍失效。

修正根页 `.data-task-surface` 的 `display:block` 覆盖 `hidden` 属性的问题：隐藏工作区不再在 Demo2 总览下方露出空的依据区域。隐藏只影响显示，不停止任务、关闭批次或启动模型。

## 后端事实映射

无 Runtime、授权、预算或 API 变更。Demo2 继续读取 Run、WorkUnit、Contribution 与 adaptive_reviews；摘要折叠不删除服务端发现。
Demo3 继续使用 office_action 的固定规则、内容版本及 action-controls。测试任务、发件回执不变为真实办公动作，也不变为模型能力。
最近列表与主任务采用独立刷新路径，截图必须等待主任务状态与实际回执一致，不能只等列表变绿或某一句等待文案消失。

本轮不证明通用任务正确性、真实动态扩编或用户体验指标提升。PPT 模板整理单独验收，本决定不声明 PPT 已完成。
