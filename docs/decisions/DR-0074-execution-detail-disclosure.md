## 场景与来源

用户在上一轮辅助面板收敛后要求“继续”。上一轮截图中，原资料库任务仍默认铺开处理历史、阶段材料、
已完成分支与全部成果版本。延续 DR-0067/0073 的按需展示，而不是改造 Runtime 或替换能力页。
这是开发者走查与用户授权，不是目标用户研究。

## 前台交互影响

- 原 `/` 任务区保留目标、当前成果与工作项；执行区不再重复完整目标，显示轮次、状态和预算。
- 普通首次处理历史、本轮过程与材料、全部完成的本轮分支、成果版本列表默认折叠，原生键盘展开。
- 续办、历史只读、来源变化、Task 查询错误的工作时间线不折叠。存在未完成分支时，分支详情不折叠。
- 来源缺口、当前待决、失败恢复、预算停止、模型输入截断提示、业务 Gate 和实际文件成果仍在原位置。
- 版本列表只是收起，不删除版本；展开后仍按原 version/幂等合同恢复，成功回执继续显示在主区。
- `/agent-capabilities` 的专门完整记录视图保持原样；原 Swarm 和单步事项不受此展示参数影响。

## 后端事实映射

只有原资料库传入 `compact` 展示属性，不新增 API、状态机或权限。折叠依据分别是 Run lineage/Owner
投影、轮次来源、该轮 Branch 状态、ArtifactVersion 与 TaskCommit；不从文本猜完成或来源。
Budget、控制状态、Gate、SSE 和已有版本校验不改。展开/收起零 POST，不调用模型；切换 Run 重建本地
详情组件，避免上一任务的输入与展开状态泄入另一个任务。
